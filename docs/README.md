# Documentacion del proyecto

Esta carpeta contiene la documentacion operativa de la web de Julio Cabos.

Empieza por estos documentos:

- `main.md`: briefing original de producto y tecnica.
- `project-overview.md`: vision general del proyecto.
- `architecture.md`: estructura tecnica, rutas y componentes.
- `content-guide.md`: como cambiar textos, enlaces, CTA, redes y SEO.
- `image-guide.md`: como gestionar hero, galeria e imagenes fuente.
- `design-system.md`: criterios visuales y reglas de interfaz.
- `forms-and-email.md`: formulario de lista de espera, Resend y variables.
- `deployment-checklist.md`: pasos antes de publicar.
- `roadmap.md`: fases futuras y decisiones pendientes.

La regla practica: si una decision afecta a marca, contenido, imagenes o mantenimiento futuro, debe quedar documentada aqui.
